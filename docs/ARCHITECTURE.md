# AURELIS Open Core Architecture v0.1

## Purpose
Create an auditable bridge between Bitcoin engineering, AI-agent coordination and legitimate funding work.

## Agent chain
1. Researcher discovers a candidate.
2. Critic attacks assumptions and looks for stale/fake information.
3. Verifier requires primary evidence and checks eligibility.
4. Synthesizer converts verified evidence into an actionable proposal.

No agent may promote UNVERIFIED evidence directly to PAID.

## Recovery boundary
Recovery research may inspect public blockchain data and user-provided backups only when ownership/authorization is established. The system explicitly excludes private-key brute force, credential theft, unauthorized wallet access and attempts to spend third-party funds.
