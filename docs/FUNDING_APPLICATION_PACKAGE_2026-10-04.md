# AURELIS Funding Application Package — 2026-10-04

## Executive proposition
AURELIS is an open-core AI coordination and verification system built around deterministic evidence, multi-agent role separation, protected-core governance, and reproducible proof-of-work. The public Open Core implements verifiable primitives and a Researcher -> Critic -> Verifier -> Synthesizer workflow. The project is extending this into funding discovery and evidence-driven task execution.

## Existing proof of work
- Transaction / Signature / Block / Chain / Validator primitives.
- Multi-agent structured communication protocol.
- Deterministic verification and evidence handling.
- Funding state machine with explicit verification and settlement states.
- Security boundary separating public Open Core from protected Temple/AURELIS core.
- Local tests and demonstration already executed.

## Proposed funded work
1. Verifiable multi-agent coordination protocol.
2. Evidence graph linking claims, tests, artifacts and decisions.
3. Adversarial verifier and red-team test suite.
4. Local-first execution with controlled network boundaries.
5. Bitcoin/cryptographic infrastructure and open-source integrations where directly relevant.
6. Public documentation, reproducible demos and benchmark results.

## ARIA Scaling Trust — Track 2 fit
AURELIS maps directly to open-source agent coordination, security reasoning and verifiable reporting. The proposal should emphasize reusable components rather than private-core functionality.

## ARIA Safeguarded AI fit
AURELIS can contribute a deterministic verification/evidence layer and adversarial test methodology, with future work targeting machine-checkable security properties.

## OpenSats fit
The strongest path is the Bitcoin/open-source branch: open-source cryptographic primitives, deterministic verification, security testing, documentation and public proof of work. OpenSats requires funded outputs to remain publicly available under an open-source license.

## Tether fit
Prioritize active tasks involving local-first AI, P2P, cryptography, tooling, integrations and open standards. Convert AURELIS components into narrowly scoped deliverables with measurable acceptance tests.

## Important application discipline
Do not claim funding, publication, awards, or payments until independently verified. Do not include private keys, seed phrases, credentials, or protected-core implementation details in public submissions.
